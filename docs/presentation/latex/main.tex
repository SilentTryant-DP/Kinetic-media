\section*{Purpose}
Prepare a six-slide presentation that demonstrates the working application and the application of DBMS concepts. The front end may be developed using any suitable language or framework, but \textbf{MySQL must be used as the database}. Replace the Inventory Management System examples below with details from your own project.

\section*{Slide 1: Project Overview}
\begin{itemize}
    \item Project title and team members.
    \item Problem statement and objectives.
    \item Main features of the application.
    \item Technologies used: front end, application language/framework, and MySQL.
\end{itemize}
\textbf{Recommended visual:} One screenshot of the application's home page or dashboard.

\section*{Slide 2: ER Diagram and Database Design}
\begin{itemize}
    \item Complete ER diagram.
    \item Entities, attributes, and primary keys.
    \item Relationships and cardinalities.
    \item Brief explanation of important database design decisions.
\end{itemize}
\textbf{Recommended visual:} The ER diagram should occupy most of the slide and remain readable.

\section*{Slide 3: Relational Schema, Functional Dependencies, and Normalization}
\begin{itemize}
    \item Final relational schema.
    \item Primary keys and foreign keys.
    \item Important functional dependencies (FDs).
    \item Normalization steps: 1NF, 2NF, 3NF, and BCNF, as applicable.
\end{itemize}
\textbf{Recommended visual:} A compact relational schema and one meaningful normalization example.

\section*{Slide 4: MySQL Implementation}
\begin{itemize}
    \item Table creation and integrity constraints.
    \item Sample database records.
    \item Two or three important SQL queries.
    \item Query outputs demonstrating joins, aggregation, or subqueries.
\end{itemize}
\textbf{Recommended visual:} Actual screenshots of SQL queries and their outputs in MySQL.

\section*{Slide 5 \& 6: Application Demonstration}
\begin{itemize}
    \item Main application interface.
    \item Add, search, update, and delete operations, where relevant.
    \item How the front end interacts with the MySQL database.
    \item One complete workflow, such as recording a sale and updating stock.
\end{itemize}
\textbf{Recommended visual:} Two or three screenshots showing a real workflow from the working application.

\section*{Slide 7: Testing, Results, and Conclusion}
\begin{itemize}
    \item Important test cases and their outcomes.
    \item Demonstration of database constraints.
    \item Reports or useful insights generated by the application.
    \item Limitations and possible future improvements.
\end{itemize}
\textbf{Recommended visual:} One result/report screenshot and a brief summary of the project's achievements.

\section*{Presentation Guidelines}
\begin{enumerate}
    \item Keep the presentation to exactly six slides, excluding any institutional cover slide if separately required by the instructor.
    \item Use screenshots from your own working application and MySQL implementation. Do not use generic images in place of implementation evidence.
    \item Include at least one actual MySQL screenshot and at least two actual application screenshots.
    \item Keep text concise. Prefer diagrams, screenshots, query outputs, and short explanations over long paragraphs.
    \item Ensure that all screenshots are readable and that personal credentials, passwords, or other sensitive information are not visible.
    \item Every team member should understand the database design, SQL queries, and application workflow and be prepared for questions.
\end{enumerate}


\noindent\textbf{Evaluation principle:} The presentation should demonstrate both a working application and sound DBMS understanding. Front-end appearance alone should not determine the project grade.
